# Chess Pro

A major React chess project built from the original Chess Web App.

## Features
- Full legal chess rules through `chess.js`
- Check, checkmate, stalemate, repetition and insufficient-material detection
- Castling, en passant and promotion
- Player vs Player and Player vs AI
- Minimax AI with alpha-beta pruning
- Undo / redo
- Move history
- Captured-piece display
- Chess clock
- Board flip
- Dark/light theme
- Sound toggle
- FEN load/copy
- PGN export
- Responsive UI

## Run
```bash
npm install
npm run dev
```

For production:
```bash
npm run build
npm run preview
```
